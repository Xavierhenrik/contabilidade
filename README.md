# Contabilidade — Papelaria

Sistema do exercício de 2026. React e Vite, dados no navegador.

Os sete menus são Início, Cadastros, Lançamentos, Estoque, Prazo, Demonstrações e Extras. O período é 01/01/2026 a 31/12/2026. O capital social é a soma do caixa, do estoque e dos bens de saldo inicial. Depreciação, amortização e provisão para garantia são apuradas em 31/12 a partir do cadastro.

```bash
npm install
npm run dev
```

`npm run build` executa os testes antes de gerar a pasta `dist`.
